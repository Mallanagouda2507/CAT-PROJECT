Configuration checklist

Set up the cloud processor to enable live extraction

  1. 1
    Create or select a Google Cloud project

    Enable billing for the project to use Document AI.

  2. 2
    Enable the Document AI API

    In the Cloud Console, enable documentai.googleapis.com.

  3. 3
    Create an Invoice Parser processor

    Choose your processor region and copy its processor ID.

  4. 4
    Configure Application Default Credentials

    Use a service account with Document AI API User permissions, or run gcloud auth application-default login.

  5. 5
    Set the environment variables

    Copy .env.example to .env and enter your project, region and processor ID.

.env
GOOGLE_CLOUD_PROJECT=your-project-id
GOOGLE_CLOUD_LOCATION=us
GOOGLE_CLOUD_PROCESSOR_ID=your-processor-id
GOOGLE_APPLICATION_CREDENTIALS=C:\path\to\service-account.json

Data and privacy

Uploaded files are stored locally for this project and are sent to Google Cloud Document AI for extraction. Extracted data and status metadata are stored in the local SQLite database. Deleting a document in the library removes its local file and record.
